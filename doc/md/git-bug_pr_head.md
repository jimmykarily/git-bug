## git-bug pr head

Record a new head commit of a pull request

### Synopsis

Record a new head commit of a pull request. Without --commit, the head is the current commit of the source branch.

```
git-bug pr head PR_ID [flags]
```

### Options

```
      --commit string   Full ID of the commit to record (default: the current commit of the source branch)
  -h, --help            help for head
```
